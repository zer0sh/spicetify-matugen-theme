# Matugen Theme for Spicetify

Dynamic theme for Spotify based on the Material You (Material Design 3) color palette generated by Matugen from the current wallpaper.

---

## 1. Design Philosophy

Unlike implementations such as Sleek (which redesign the interface, alter panel layout and change element sizes), this theme focuses exclusively on:

* **Clean and coherent color scheme:** Faithful adaptation of the Material Design 3 semantic color roles over the vanilla Spotify interface (XPUI).
* **Zero invasive layout changes:** Preserves the official layout, responsiveness and all original player controls.
* **Real-time synchronization:** It regenerates automatically every time Matugen updates the system palette with a new wallpaper.

---

## 2. Integration Architecture

The theme generation and application flow works as follows:

```text
Wallpaper (~/.config/themes/current/wallpaper)
                    |
                    v
             [ matugen image ]
                    |
                    v (processes ~/.config/matugen/templates/spicetify.ini)
~/.config/themes/current/spicetify.ini
                    |
                    v (symbolic link)
~/Workspace/personal/spicetify/themes/matugen/color.ini
                    |
                    v (symbolic link into Spicetify Themes)
~/.config/spicetify/Themes/matugen/
                    ├── color.ini -> ~/.config/themes/current/spicetify.ini
                    └── user.css  -> Adaptive color styles
```

---

## 3. Installation and Activation

### Step 1: Link the theme into Spicetify
Create the symbolic link in the Spicetify themes directory:

```bash
ln -sfn "$HOME/Workspace/personal/spicetify/themes/matugen" "$HOME/.config/spicetify/Themes/matugen"
```

### Step 2: Configure Spicetify
Set `matugen` as the active theme and select the matching color scheme:

```bash
spicetify config current_theme matugen
spicetify config color_scheme matugen
spicetify config inject_css 1 replace_colors 1
```

### Step 3: Apply Changes
Apply the configuration to the Spotify client:

```bash
spicetify apply
```

## 4. Material Design 3 Color Role Mapping

The `spicetify.ini` template binds Matugen roles to Spicetify variables:

| Spicetify Variable | Matugen Role | Purpose in Spotify |
| :--- | :--- | :--- |
| `main` | `surface` | Main background of the navigation view |
| `sidebar` | `surface_container_lowest` | Left sidebar (Your Library) |
| `player` | `surface_container_low` | Bottom player bar |
| `card` | `surface_container` | Album, playlist and artist cards |
| `text` | `on_surface` | Primary text and titles |
| `subtext` | `on_surface_variant` | Metadata, secondary artists and durations |
| `button` | `primary` | Play button, active sliders and accents |
| `button-active` | `primary_container` | Hover state on interactive buttons |
| `button-disabled` | `outline_variant` | Inactive progress and volume bars |
| `notification-error` | `error` | Critical states and errors |

---

## 5. Dynamic Updates with Wallpapers

When `apply-matugen.sh` runs (for example, from the wallpaper selector in Quickshell), the script rewrites `~/.config/themes/current/spicetify.ini` and automatically runs:

```bash
spicetify apply -n
```

The `-n` flag updates the Spotify theme without restarting the application.
